# Ember & Oak — Wood-Fire Steakhouse

A single-page "dark luxury" landing page for a fictional wood-fire steakhouse, built entirely with Claude Code (HTML/CSS/JS, no framework).

**Live site:** https://khoishpy123.github.io/ember-oak-steakhouse/

## Highlights
- Full-screen serif hero (Cormorant Garamond, embedded as woff2 so fonts never fail to load)
- CSS-only fire atmosphere: flickering ember glows, drifting sparks, film grain, vignette
- Scroll-triggered reveals, sticky blurred header, hover micro-interactions
- Fully responsive, respects `prefers-reduced-motion`
- Zero external requests — the whole page is self-contained in `index.html`

## Deploy
It's a static file. Just serve `index.html` from any host (GitHub Pages, Netlify, Vercel, Cloudflare Pages).
